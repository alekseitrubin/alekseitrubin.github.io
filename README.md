# Aleksei Trubin — Portfolio

Lightweight Jekyll portfolio deployed with GitHub Pages. It includes the project-first professional homepage and the preserved [academic CV](/academic/).

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/`.

After building, run `bundle exec ruby scripts/validate_site.rb` for structural, metadata, accessibility, and internal-link checks.
